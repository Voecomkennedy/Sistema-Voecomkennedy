Dicas de Backup
  • Seus dados são salvos automaticamente no navegador (LocalStorage)
  • Exporte o backup e salve na pasta do Google Drive para sincronizar automaticamente
  • Faça backup pelo menos uma vez por semana ou após vendas importantes
  • Se limpar os dados do navegador, você perderá os dados locais. Sempre tenha um backup externo!
